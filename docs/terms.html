이용약관

1. 서비스 목적

LiveNote는 브라우저 기반 실시간 음성 자막, 자막 저장, AI 요약, 공유 자막 기능을 제공하는 보조 도구입니다. 생성 결과는 참고용이며 공식 기록이나 법적 증빙을 대체하지 않습니다.

2. 이용 조건

이용자는 본인의 권한이 있는 오디오 입력과 콘텐츠에 대해서만 서비스를 사용해야 합니다. 타인의 대화, 강의, 방송, 회의 등을 녹음하거나 자막화할 때에는 필요한 동의와 권리를 확보해야 합니다.

3. 금지 행위

불법적인 목적, 타인의 권리 침해, 개인정보 무단 수집, 저작권 침해, 서비스 과부하 유발, API 남용, 악성 코드 삽입, 광고 시스템 조작, 기타 부정한 목적으로 서비스를 사용할 수 없습니다.

4. AI 결과의 한계

음성 인식과 AI 요약 결과는 배경 소음, 발음, 언어, 모델 특성, 네트워크 상태에 따라 부정확할 수 있습니다. 의료, 법률, 금융, 안전과 관련된 중요한 판단에는 원문 확인과 전문가 검토가 필요합니다.

5. 서비스 변경 및 중단

운영상 필요, 외부 API 장애, 브라우저 정책 변경, 보안 이슈, 점검 등으로 서비스의 일부 또는 전부가 변경되거나 일시 중단될 수 있습니다.

6. 책임의 한계

서비스 제공자는 고의 또는 중대한 과실이 없는 한 AI 결과의 오류, 이용자의 권리 미확보, 외부 API 장애, 브라우저 저장 데이터 삭제, 네트워크 문제로 인한 손해에 대해 책임을 지지 않습니다.

7. 광고

서비스에는 Google AdSense 등 광고가 표시될 수 있습니다. 이용자는 광고 클릭을 유도하거나 광고 시스템을 조작하는 행위를 해서는 안 됩니다.

개인정보처리방침

LiveNote는 회원가입 없이 사용할 수 있는 실시간 자막 도구입니다. 서비스 제공에 필요한 범위에서 마이크 입력, 자막 텍스트, 브라우저 저장 데이터, 광고 관련 식별자가 처리될 수 있습니다.

1. 처리하는 정보

서비스는 실시간 자막 생성을 위해 사용자가 선택한 마이크 또는 오디오 입력을 브라우저에서 처리합니다. 생성된 자막, 글자 크기와 색상 설정은 사용자의 브라우저 localStorage에 저장될 수 있습니다.

고정밀 클라우드 자막 모드 사용 시 음성 파일 조각이 음성 인식 API 제공업체(Groq 등)로 일시 전송될 수 있습니다. AI 요약 또는 질문 기능 사용 시 자막 텍스트와 질문이 생성형 AI API 제공업체(Google Gemini 등)로 전송될 수 있습니다. 공유 자막 기능 사용 시 방 번호와 자막 텍스트가 실시간 전송 서비스(Supabase 등)를 통해 다른 참여자에게 전달될 수 있습니다.

2. 처리 목적

수집 또는 전송되는 정보는 실시간 자막 생성, 자막 표시와 다운로드, AI 요약과 질의응답, 공유 자막 전송, 서비스 오류 대응, 광고 게재와 부정 이용 방지를 위해 사용됩니다.

3. 보관 기간과 삭제

서비스는 회원 계정을 운영하지 않으며, 음성 데이터와 자막 텍스트를 자체 서버에 영구 저장하지 않습니다. 브라우저에 저장된 자막과 설정은 사용자가 화면의 초기화 기능을 사용하거나 브라우저 저장소를 삭제하면 제거할 수 있습니다. 제3자 API로 전송된 데이터의 보관 여부와 기간은 각 제공업체 정책을 따릅니다.

4. 제3자 서비스

서비스 운영 과정에서 Google AdSense, Google Gemini API, Groq API, Supabase 등 외부 서비스가 사용될 수 있습니다. 각 서비스는 요청 처리, 광고 게재, 보안, 품질 개선을 위해 IP 주소, 쿠키, 웹 비콘, 기기 식별자, 요청 본문 일부 등 필요한 정보를 처리할 수 있습니다.

5. 광고 및 쿠키

본 사이트는 Google AdSense 광고를 게재할 수 있습니다. Google 및 제3자 광고 사업자는 광고 제공과 맞춤형 광고를 위해 쿠키, 웹 비콘, IP 주소 또는 기타 식별자를 사용하거나 사용자의 브라우저에 쿠키를 설정하고 읽을 수 있습니다.

사용자는 브라우저 설정 또는 Google 광고 설정에서 맞춤형 광고를 제한할 수 있습니다. Google이 파트너 사이트 또는 앱에서 데이터를 사용하는 방식은 Google 안내 페이지에서 확인할 수 있습니다.

6. 이용자 유의사항

타인의 음성, 회의, 강의, 방송 등을 자막화하거나 공유할 때에는 관련 법령, 저작권, 초상권, 녹음 동의 의무를 준수해야 합니다. 민감한 개인정보, 비밀번호, 결제정보, 의료정보 등은 자막 또는 AI 질문에 포함하지 않는 것을 권장합니다.

7. 보안

서비스는 HTTPS 환경에서 제공되는 것을 전제로 하며, API 키와 서버 설정값은 클라이언트에 노출되지 않도록 관리합니다. 단, 인터넷 전송과 외부 API 이용에는 일반적인 보안 위험이 존재할 수 있습니다.
